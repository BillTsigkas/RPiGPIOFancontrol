A simple Python script with some basic electronics for controlling (start/stop) your Raspberry Pi Zero 2 W cooling fan without the need to spin 24/7 at full speed.
In my case the RPi handles my PiHole+PiVPN and my car's server alarm. A mini UPS is highly recommended.
